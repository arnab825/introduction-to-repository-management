# Contributing to Mergington High School's Extracurricular Activities Website

We are thrilled that you'd like to contribute! Your help is essential for keeping our school's extracurricular activities website organized, helpful, and up to date.

## Ways to Contribute

### 🐛 Report Issues
Found a bug, outdated schedule, or something that could be improved? Open an issue!
- Use a **descriptive title** and **detailed description** so we can understand and prioritize the problem.
- Check existing issues before creating a new one to avoid duplicates.

### 🔧 Quick Fixes
See a typo, broken link, or other small problem? Fork the repository and submit a pull request directly.
1. Fork the repository.
2. Make your change, push to your fork, and open a pull request.
3. Wait for your pull request to be reviewed and merged.

### 💡 Larger Changes
For significant changes or new features, please **open an issue first** to discuss your proposal with the maintainers before writing code.
